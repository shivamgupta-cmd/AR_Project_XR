Ocean Water PRO Lit for Unity 2022 URP.
Run Tools > Ocean Water PRO > Create Ocean Material.
Assign M_OceanWater_PRO_LIT to the ocean mesh.
Uses only Normal Map + Foam Texture: no Ripple/Caustics texture fields.
Recommended: Transparency .85-.95, Directional Light, HDR and Bloom.
The mesh needs enough vertices for geometric wave displacement; a single quad only shows surface normal animation.

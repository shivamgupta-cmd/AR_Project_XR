BOUNDED GAS VAPOR FX
Copy BoundedGasVaporFX into your Unity project's Assets folder.

Assets/BoundedGasVaporFX/Generated/BoundedGasVapor.prefab

If needed:
Tools > Bounded Gas Vapor FX > Create or Refresh Prefab

This version is intentionally stable:

- nearly zero velocity

- subtle internal Noise
- two cloud layers
- Local simulation

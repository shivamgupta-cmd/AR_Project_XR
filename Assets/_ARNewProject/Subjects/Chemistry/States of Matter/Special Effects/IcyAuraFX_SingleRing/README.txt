ICY AURA FX — SINGLE RING VERSION
=================================

This version fixes the previous behavior.

You get ONE single glowing ring (not multiple ring particles).
The ring rotates continuously using IcyRingRotator.

Snowflakes and sparkle motes are emitted slowly from the ring area.

Generated prefab:
Assets/IcyAuraFX_SingleRing/Generated/IcyAuraFX_SingleRing.prefab

If it does not auto-generate:
Tools > Icy Aura FX Single Ring > Create or Refresh Prefab

Hierarchy:
IcyAuraFX_SingleRing
├── Single_Glowing_Ring
├── Slow_Snowflakes_From_Ring
└── Sparkle_Motes_From_Ring

Usage:
Place the parent at the base of the ice cube.
Scale the parent until the single ring surrounds the cube.
